## What the screen supports

Seven of these eight models pass the current exact-weld topology gate; ABeautifulGame fails. GlassBrokenWindow is valid only as a low-detail case for now. Two passing assets contain marks excluded from the model license, so any later textured image evaluation must remove those marks or use geometry-only shading. Passing topology does not prove visual suitability, a clean confirmation split, or licensing of every transformed/rendered artifact.

Together with the earlier CommercialRefrigerator and ScatterPlant checks, the repository now has **nine provisional geometry candidates** across several object classes. This is a candidate pool, not a held-out dataset: source selection and categories have not been frozen, and most models are Khronos material/extension showcase assets. The 20-asset, five-category confirmation requirement is still unmet. No PSNR, SSIM, FLIP, LPIPS, silhouette, temporal, or runtime result follows from this screen.

The bounded reuse audits ran [`audit_asset_reuse.py`](../../tools/mmtrain/audit_asset_reuse.py) against 277 text artifacts in the public research checkout at commit `37c03688399c92becdd959d0e327d83501daac20`. Each scan searched the source binary hash, filename, and stem. No matches were found. This cannot rule out unarchived use, renamed copies, or geometric derivatives.

The extractor merges default-scene static triangle primitives at default node transforms and ignores materials and animation channels. Topology uses exact-coordinate welding and does not assess semantics, near-coincident seams, intersections, silhouette quality, or image quality. See the receipts for hashes and scope.
